## 練習內容

### My Favorite Planet

以火星為主題，練習 HTML 的基礎文字標籤，包括：

- 標題與段落：`h1`、`h2`、`h3`、`p`
- 文字格式：`b`、`i`、`em`
- 換行與分隔線：`br`、`hr`
- 上標與下標：`sup`、`sub`
- 縮寫與提示文字：`abbr`、`acronym`
- 行內 CSS 樣式：`style`
