# Web Programming Course

這個 Repository 用來整理網頁程式設計課程的每週練習與中期專案。練習內容包含 HTML 文件結構、CSS 排版、導覽列、表格、圖片與 JavaScript 互動。

- [查看 GitHub Repository](https://github.com/sshen714/web-programming-course)

## Midterm Project

### 今天吃什麼？

中期專案是一個簡單的數位美食指南。使用者可以選擇早餐、午餐、晚餐或飲料，再使用旋轉輪盤隨機選出一個餐點。

專案包含：

- 五個可互相連結的 HTML 頁面。
- 每個頁面共用的導覽選單。
- 使用 `<div>` 與 CSS Grid 建立的 2 × 2 餐點卡片。
- 包含 `alt` 替代文字的圖片。
- 飲料品牌表格、內部連結與外部連結。
- 使用 JavaScript 建立的主題切換與隨機輪盤。

### Midterm Pages

| 頁面 | 功能 |
| --- | --- |
| `midterm/index.html` | 主題選擇與隨機輪盤 |
| `midterm/breakfast.html` | 早餐圖片與餐點介紹 |
| `midterm/lunch.html` | 午餐介紹與參考價格 |
| `midterm/dinner.html` | 晚餐介紹與參考價格 |
| `midterm/drinks.html` | 台灣飲料品牌特色表格 |

## Weekly Exercises

| 資料夾 | 練習重點 |
| --- | --- |
| `week1` | HTML 標題、段落與基本文字標籤 |
| `week2` | 連結狀態與頁面內容區塊 |
| `week3` | 無序清單、導覽列與多頁連結 |
| `week5` | 圖片、float、margin 與圓角 |
| `week6` | HTML 表格、`rowspan` 與 `colspan` |
| `week7` | JavaScript 動態產生九九乘法表 |
| `week10` | JavaScript DOM 操作與 Canvas 點擊事件 |
| `week11` | Canvas 路徑與折線繪製 |
